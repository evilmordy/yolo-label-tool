# YOLO 标注工具 (YOLOTxtMaker)

一个功能完整的YOLO数据集标注工具，提供直观的GUI界面用于创建和编辑YOLO格式的标注文件。


注意：标注文件写在「保存路径」里。第一次使用（或上次选的目录已经不存在）时，必须先点 **设置保存路径**，才能打开图片或文件夹。选过之后会记住，下次启动自动填上，目录还在就不用重选。
## 使用

### Windows
在 [Release 页面](https://github.com/evilmordy/yolo-label-tool/releases) 下载 `YOLOTxtMaker.exe`，运行它。
### Linux
在 Release 页面下载 `YOLOTxtMaker.AppImage`，赋予执行权限后运行：

```bash
chmod +x YOLOTxtMaker.AppImage
./YOLOTxtMaker.AppImage
```

### macOS
在 Release 页面下载 `YOLOTxtMaker-mac.zip`，解压后运行其中的 `YOLOTxtMaker.app`。

### 下载代码在本地运行
git clone项目到本地，然后安装这两个库：pyqt5,pillow.
直接运行main.py即可。

## 发布新版本

合并到 `main` 后，GitHub Actions 会自动把 patch 版本加一（例如 `v2.0.1` → `v2.0.2`），构建 Windows exe、Linux AppImage、macOS zip，并发布到 [Release 页面](https://github.com/evilmordy/yolo-label-tool/releases)。

也可以继续手动推送 `v*` tag，或在 Actions 里点 **Run workflow**，同样会出三平台安装包。



## 快捷键

在标注界面中可用（焦点在窗口内时生效）：

| 按键 | 说明 |
|------|------|
| **R** | 切换到**标准矩形（Rect）**模式；之后点击「新添」会创建轴对齐矩形框 |
| **O** | 切换到 **OBB（旋转矩形）**模式；之后点击「新添」会创建带旋转控制点的框 |
| **P** | 切换到 **多边形（Seg）**模式；之后点击「新添」进入逐点绘制 |
| **Enter** | 绘制多边形时闭合当前多边形（至少 3 个顶点） |
| **Esc** | 绘制多边形时取消当前绘制 |
| **Ctrl+S** | 保存当前图片 YOLO txt |
| **B** | 把当前图标记为背景：立刻写入空 txt（若已有框会先清掉，可用 Ctrl+Z 撤回） |
| **Ctrl+Z** | 撤回上一步标注操作 |
| **A** | 新增标注（多边形绘制中不生效） |
| **Delete** | 删除当前选中标注；多边形绘制中则取消绘制 |
| **← / →** | 上一张 / 下一张图片（需先打开文件夹；单张图模式无效果） |
| **Backspace** | 多边形绘制中撤销上一个顶点 |

说明：R / O / P 只切换「当前新建框的类型」，不会改变已有标注；右侧单选按钮与上述快捷键一一对应。

默认快捷键可在菜单栏 **设置** 中自定义，并支持「恢复默认快捷键」。

## 设置

点击菜单栏 **设置** 直接打开偏好面板，可配置：

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 切换图片时自动保存 | 上一张/下一张/列表切换前，仅当当前图有未保存改动时写 txt | 开启 |
| 启用定时自动保存 | 按间隔只保存当前有未保存修改的图片，不改写其它 txt | 关闭 |
| 定时间隔 | 定时保存间隔（分钟） | 5 |
| 语言 | 中文 / English / 日本語 | 跟随系统语言（中文、日文系统用对应语言，其它系统用英文） |
| 快捷键 | Ctrl+S、B、Ctrl+Z、A、Delete、R、O、P、Enter、Esc 等，可点击输入框后按键修改 | 见上表 |

说明：关闭「切换图片时自动保存」后，未手动保存的编辑在切图时会丢失。开启时也只写有改动的图片，单纯翻页不会新建 txt。定时保存同样只写入当前有未保存修改的图片，不会重写文件夹里其它未改动的 txt（保留原有数字格式，也不会丢掉解析不了的行）。

## 注意：
代码用的是with open 和写入模式，是覆盖式的，所以如果之前有同名文件，会被覆盖。但这也有好处，因为软件会加载保存路径里现有的标注



## 功能特性

###  图片管理
-  支持打开单张图片
-  支持打开整个文件夹进行批量标注
-  "上一张"和"下一张"按钮快速浏览图片,也可以在文件列表里选择图片
-  图片计数器显示当前进度（如 `3/10`）
-  切换图片时，只有当前图真的改过才自动保存
-  图片列表按文件名的自然顺序显示（`img2` 在 `img10` 前面），并用前缀区分标注状态
-  列表前缀：`○` 未标注（没有 txt）、`□` 背景（空 txt）、`✓` 已标注（txt 非空）、`●` 当前图有未保存修改
### BBox标注
-  新增BBox（自动居中于图像）
-  删除选中的BBox
-  8个拉伸控制点（4个角 + 4条边）
-  鼠标悬停时控制点高亮显示
-  拖拽移动BBox
-  **严格边界检查** - BBox永远不会超出图像范围

### OBB标注

- 可能会超出边界
- 四个角控制点，一个旋转控制点

### Seg 多边形标注

- 与 Rect / OBB **共用同一 `.txt` 文件**，按行混存
- 选择「多边形(Seg)」后点击「新添」，在画布上**左键逐点**添加顶点
- **Enter** 或 **双击首点附近**闭合多边形（至少 3 点）；**Esc** 取消绘制
- **Backspace** 撤销上一个顶点
- 编辑：拖拽顶点；拖拽多边形内部整体平移
- 顶点严格限制在图像范围内

#### YOLO Seg 格式

每行一个实例，归一化顶点坐标（相对图像宽高）：

```
class_id  x1 y1  x2 y2  x3 y3  ...  xn yn
```

示例：

```
0  0.681 0.485  0.670 0.487  0.676 0.487  0.688 0.515
1  0.422 0.315  0.438 0.330  0.445 0.328  0.450 0.320  0.435 0.310
```

**字段数识别规则**（加载时）：

| 字段数 | 类型 |
|--------|------|
| 5 | 标准矩形 (Rect) |
| 9 | OBB 旋转框（4 顶点） |
| 7, 11, 13…（奇数且 ≥7，且 ≠9） | Seg 多边形 |

> **注意**：恰好 9 个字段的行会被解析为 **OBB**，而非 4 顶点的 Seg 多边形。若需要 4 顶点矩形 mask，请使用 OBB 模式，或标注时使用 **≥5 个顶点**。

### 标签管理
-  修改Class ID（通过右侧SpinBox）
-  列表显示：`[Rect]` / `[OBB]` / `[Poly] IDx | Class: y`（多边形另显示顶点数）
-  点击列表项选中对应BBox
-  点击图像中的BBox自动同步到列表
-  单选模式：同时只有一个BBox为紫色

### 保存和加载
-  打开图片 / 文件夹前必须已有有效的保存路径
-  第一次手动选择；之后启动会自动恢复上次的目录。若目录被删或失效，需要再选一次
-  对应的 `.txt` 从该保存路径加载，保存时也写回这里（同名文件会覆盖）
-  可手动保存，或在切换图片时自动保存有改动的图片

### 背景图（无目标）

YOLO 训练需要把「这张图里没有目标」和「这张图还没标」分开。没有 txt 的图片是**未标注**；保存路径里有一个**空 txt** 的图片是**背景图**（负样本），可以进训练。

- 用上一张 / 下一张 / 列表翻页，只要没改标注，**不会**新建 txt
- 原来有框，把框全部删掉后再切换图片，会写入空 txt（这张图被确认成背景）
- 按 **B**，或菜单 **文件 → 标记为背景**，或右侧 **标记为背景**，立刻为当前图写入空 txt。若当前还有框，这些框会被清掉；**Ctrl+Z** 可以撤回，撤回后切图会按修改重新保存
- 没有框时按 **Ctrl+S** 同样会写入空 txt

列表里三种落盘状态颜色也不同：已标注为绿色，背景为蓝色，未标注为灰色；当前图有未保存修改时为橙色圆点。
